# IM LIFESTYLE - Premium Footwear eCommerce Website

## 🎯 Project Overview

A **high-converting premium eCommerce website** for IM Lifestyle, a trendy and affordable footwear store in Tiruppur, Tamil Nadu. The website is fully functional, mobile-responsive, and designed to resemble modern footwear brands like Nike, Puma, and Adidas.

### Key Features Implemented ✓

- **Premium Design**: Modern luxury minimalism with clean typography
- **Product Catalog**: 25+ products across 5 categories with auto-generated cards
- **Dynamic Filtering**: Category, Gender, Price Range, Size, Color filters
- **Advanced Search**: Real-time product search functionality
- **Quick View Modal**: Product details with image gallery, specifications, and options
- **Shopping Cart**: Add/remove items, quantity management, persistent storage
- **Checkout Flow**: Complete customer information & payment method selection
- **WhatsApp Integration**: Direct WhatsApp ordering for all products and cart
- **Responsive Design**: Mobile-first approach with adaptive layouts
- **Animations**: Smooth transitions, hover effects, loading states
- **Trust Badges**: Reviews, ratings, customer testimonials
- **SEO Optimized**: Schema markup, meta tags, keywords

## 🚀 How to Use

### 1. **Open the Website**
```bash
# Simply open in any modern browser
Open: index.html
```

### 2. **View All Products**
- **Hero Section**: Click "Shop Now" or scroll down
- **Categories**: Click on any category card (Sneakers, Crocks, Slides, Ladies, Men & Boys)
- **Browse All**: Navigate to the "All Products" section

### 3. **Search & Filter Products**
- Use the search bar in the navbar to find products
- Apply filters by:
  - Category
  - Gender (Men, Women, Kids, Unisex)
  - Price Range
  - Size
  - Sort (Newest, Price Low→High, Rating, Popular)

### 4. **Quick View Products**
- Click "👁 Quick View" on any product card
- View detailed images, prices, ratings, and specifications
- Select size, color, and quantity
- Choose action:
  - **Add to Cart**: Continue shopping
  - **Buy Now**: Go directly to checkout
  - **Order via WhatsApp**: Direct WhatsApp ordering

### 5. **Shopping Cart**
- Click the 🛒 Cart button in navbar
- View all items with sizes and colors
- Adjust quantities
- Enter coupon code (try: SAVE10, WELCOME, FIRST)
- Proceed to checkout or order via WhatsApp

### 6. **Checkout**
- Fill in customer details
- Choose payment method:
  - **Cash on Delivery (COD)**
  - **UPI Payment**
  - **WhatsApp Payment**
- Complete the order

### 7. **Contact Options**
- **WhatsApp**: Floating button or direct messaging
- **Instagram**: Follow @im_lifestyle_tirupur
- **Phone**: +91 8838247446
- **Contact Form**: Fill and submit for inquiries

## 💡 Customization Guide

### To Add New Products

1. Edit `products.js`
2. Add to `productsDatabase` array:
```javascript
{
    id: 'product-xxx',
    name: 'Product Name',
    category: 'category-key',
    gender: 'men/women/kids/unisex',
    price: 599,
    originalPrice: 899,
    rating: 4.8,
    reviews: 100,
    image: '👟',
    colors: ['Black', 'White'],
    sizes: [7, 8, 9, 10],
    description: 'Description here',
    specifications: { ... },
    inStock: true,
    featured: true,
    new: true
}
```

### To Change Colors

Edit CSS variables in `styles.css`:
```css
:root {
    --primary-color: #000000;
    --secondary-color: #FFFFFF;
    --accent-color: #FF6B00;
    --neutral-color: #F5F5F5;
}
```

### To Add Coupon Codes

Edit `products.js` coupons:
```javascript
const coupons = {
    'NEWCODE': { discount: 20, type: 'percentage' },
};
```
